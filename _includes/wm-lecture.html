How a latent world model works, from pixels to plans.

V-JEPA 2 learns to see by predicting hidden video in a feature space it invents. V-JEPA 2-AC turns that encoder into a world model a robot can plan with. H-JEPA stacks such models at several timescales. This lecture takes each one apart, from the input tensor to the output action, with the mathematics, the code that implements it, and sixteen labs in which you train, break and plan with small versions of the same machinery.
