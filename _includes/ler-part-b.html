Part 06

Hardware is source code

A YAML spec goes in, a parametric and version-controlled robot comes out, and the CAD program is demoted to a viewer. Talk, Implication 1 Talk

The pipeline from the talk has six steps:

  1. Spec. A YAML file holds dimensions, masses, actuators and joint limits.
  2. Program. The agent writes Python, typically with the open-source parametric library build123d, that builds every part in memory.
  3. Export. Each part is written out as a STEP file.
  4. Assemble. The program joins the parts, sets joint types, limits and values, and assigns materials and densities. build123d ships rigid, revolute, linear, cylindrical and ball joints, with limits as angular_range and linear_range.
  5. Inspect. The agent checks the result; Fusion 360 or similar is opened only to look.
  6. Extend. The same agent attaches simulation, system identification and control.

The payoff is hardware that behaves like software: it can be regenerated, branched, diffed, reviewed and optimized in the same loop as its controller. The lab below runs that loop on a toy planar arm.

    Part 07
    
  
    Noise is a representation problem
    
  
    The exact details of a motion are redundant. What decides success is the representation the policy
    learns, and where noise is added back into it.
    Talk and discussion Talk
    
  
    Two demonstrations of the same grasp differ in timing, path and wrist angle, and most of that variation does not change
    the outcome. The discussion's claim is that adding noise back, probably inside representation space rather than raw
    joint space, determines final success. The target it named is continuous dynamics inside a discrete space: a finite
    token vocabulary whose embeddings still respect continuity.
    
  
      
    
    • VQ-VAE (van den Oord et al., 2017) encodes an input, snaps it to the nearest entry of a learned codebook, and decodes from that discrete code. It is the natural interface for any modality. Measured
      • 
    
    • ViT (Dosovitskiy et al., 2020) is the precedent for brute force: cut an image into 16×16 patches, project them linearly, drop the convolutional prior. Strictly, ViT's patch tokens are continuous embeddings; the discrete step belongs to VQ-VAE. Measured
      • 
    
    • VQ-BeT (Lee et al., ICML 2024) tokenizes continuous actions with residual vector quantization. Measured
      • 
    
    • FAST (Pertsch et al., Physical Intelligence, January 2025) applies a discrete cosine transform to an action chunk, quantizes the coefficients and compresses them with byte-pair encoding, typically into 30 to 60 tokens. π0-FAST matches the diffusion-based π0 while training up to five times faster, where naive per-dimension binning could not learn the dexterous tasks at all. The price is slower autoregressive decoding. Measured
      •

    Part 08
    
  
    A language for control
    
  
    The language model can be the reward model, the trainer, the planner and the controller. To make it a
    controller, invent a control language, or just use Python and tool calls, and attach each tool to its own harness.
    Talk, Implication 3 Talk
    
  
    Three claims sit inside this. In-context learning comes free of robot data. Reflexes can be trained into the
    language model itself instead of living in a hand-built controller. And the interface between the model and the robot
    is a design choice that can be written down. Talk The first is now measured, with a catch:
    free of robot data is not free of design. The same model got worse with naive demonstrations (Part 03) and much
    better with a structured context.
    

  
    RoboICL's grammar
    
  
    RoboICL (Liu et al., arXiv 2609.34261) gives the model one action tool. The model emits a continuous action chunk and
    a short note; deterministic code validates it, solves inverse kinematics and executes the admissible prefix.
    Write-up Everything in context, whether a recorded demonstration or the model's own last
    attempt, is written in one grammar: observation, action chunk, execution receipt, result observation. Sampled
    demonstration blocks sit beside a bounded memory with fixed anchors, so early experience survives later stages, and
    the latest interaction is always present for immediate correction. When steps are discarded, an explicit
    <TRAJECTORY_GAP> record stops the model reading two blocks as consecutive. Measured
    

  
    
    
    Build the context
    
    
    
      
    
        
        
        
      
    
      
      
      
    
    
    
    
    
    
    
    
  
    
  
    On two development tasks, an optional Jev-gated action reuse cut Astra calls by 33 to 48%, which matters
    for Part 09's speed budget. On a ten-task subset RoboICL with Astra alone scores 60.60 against 62.60 reported for a
    π0.5 plus Astra ensemble. Measured
    

  
    Tools as backends: AgentSTAR
    
  
    AgentSTAR (Mazur, Karaev, Chang, Malik and Shafiullah, arXiv 2609.24487) reconstructs and tracks articulated objects
    from one monocular video. A vision-language agent refines shape and generalized pose in a render-and-compare loop,
    mixing coarse visual reasoning with numerical pose optimisation, and the output is a structured 3D object model with
    parts, joint axes and pivots. It beats 3D point-tracking baselines for articulated objects on ARCTIC and every
    evaluated rigid-object tracker on HOT3D. Measured The discussion's point is the role it
    could play: a kinematic-replay backend that an agent calls when it needs an object's geometry, the way a coding agent
    calls a compiler. Talk
    

    



    
  
    Part 09
    
  
    Low-level control without chain-of-thought
    
  
    Low-level control does not need chain-of-thought, and nothing stops a language model from skipping it.
    Give the output format room to reason when needed and to act directly otherwise.
    Discussion Talk
    
  
    Rotations, simple contacts and kinematic primitives are intuitive: they need neither reasoning nor tokens spent on
    it. The continuous dynamics underneath may need a JEPA-style model, which the discussion did not see as a
    contradiction of the thesis. There is no need to inject these skills into the weights; the output format can force the
    choice. Talk
    
  
    Shipped systems already make this choice. π0.5 decodes discrete tokens for high-level steps and continuous
    flow-matching outputs for motor commands, in one model. Measured In the Galbot hybrid,
    Astra passed π0.5's actions through and rewrote only 14.4% of control steps. On RoboCurve's bowl task Astra spent
    2.1k output tokens per run against 12.9k for Claude Fable 5.1, and succeeded 19 times to 8. That is a cross-model
    comparison, so it does not isolate thinking, but heavy token use was clearly not required. Demo

    The control-rate budget
    
      
    A controller must deliver an action every 1/f seconds. Each model call costs a fixed latency plus its reasoning
        tokens, and returns a chunk of actions. Find the settings that keep up with the robot.

    • Chunk 25 actions per call and the same latency keeps up; add 1,500 reasoning tokens and it falls behind again.
    
      
    What it shows, and what it does not
    Why speed sits at the bottom of the difficulty ordering and why
        reasoning has to be optional at control rate. Astra's real latency and decode speed are not published; the sliders
        are assumptions, not measurements. Reviewer
    
    
    
  
    

  
    Two architecture pointers
    
  
    RoboJEPA as a residual. The discussion proposed placing a RoboJEPA-style world model beside the language model
    to absorb the low-level dynamics the language model should not reason about. The RoboJEPA paper itself has no such
    module; "residual" is the discussion's proposal. Talk
    
  
    Attention Residuals. Kimi's AttnRes (arXiv 2603.15031) replaces the fixed, unit-weight residual sum of PreNorm
    transformers with softmax attention over all earlier layer outputs, so each layer chooses which depths to read with
    learned, input-dependent weights. Block AttnRes attends over block summaries to save memory. In Kimi Linear (48B total,
    3B active) pre-trained on 1.4T tokens it improved every evaluated downstream task. Measured
    The write-up's reading of why it came up: if each layer can choose its depth, shallow intuitive features and deep
    reasoning features can live in one network. Write-up

    Part 10
    
  
    One system or two
    
  
    A System 1 and System 2 split makes sense as an intermediate step. If end-to-end is possible, you do
    end-to-end.
    Talk Talk
    
  
    The boundary is blurrier than the labels. Figure's Helix runs a 7 to 9 Hz vision-language model as System 2 and a
    200 Hz visuomotor policy as System 1, and trains the pair end-to-end. Measured So the useful
    question is not one system or two but whether the interface between them is learned or hand-designed. Click a system
    to place it on that axis.
    
  
    
    
    
      
    
      hand-designed interface
      learned end-to-end
    
    
    
    
  
    
  
    Current data cut both ways. On bimanual RoboDojo tasks the π0.5 plus Astra hybrid beat Astra alone, 48% to 26%. On
    simpler single-arm RoboLab tasks Astra alone won, 98% to 92%. Write-up
    
  
    Reviewer's margin
    
    Neither comparison holds compute and data fixed. The experiment the take needs is end-to-end against dual-system on
      identical tasks at equal training compute and equal robot data, which nobody has run at this scale.
