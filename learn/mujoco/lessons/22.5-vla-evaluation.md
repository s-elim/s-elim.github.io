## Core concept

Evaluating a vision-language-action policy by a single average success rate conceals the physical and cognitive causes of success and failure. An aggregate score of 75% does not reveal whether the policy fails because it cannot parse synonyms, cannot extrapolate beyond the table center, struggles with visual clutter, or fails when actuator dynamics change.

Rigorous evaluation factors performance into orthogonal generalization axes: language, objects, spatial layout, initial states, camera viewpoint, and robot embodiment. Each axis tests a specific invariant:

1. Language: invariance to phrasing (paraphrase), vocabulary (synonyms), and novel combinations of familiar concepts (compositionality).
2. Objects: invariance to geometry (size) and photometric properties (color).
3. Spatial layout: extrapolation to workspace regions unvisited in demonstrations.
4. Initial states: resilience to clutter and distractor proximity.
5. Camera viewpoint: robustness to small extrinsic calibration errors.
6. Embodiment: robustness to end-effector dimensions and actuator response limits.

This lesson measures the patch MiniVLA across eleven isolated conditions in MuJoCo, reporting 95% Wilson confidence intervals across three seeds and seed-matched generalization gaps. It also demonstrates how the same factored protocol evaluates 7-DOF Franka arm manipulation.

## Visual intuition

Factored evaluation isolates variables by intervening on exactly one physical or semantic property at a time, holding all other scene parameters constant.

In the tabletop benchmark, the training distribution places red, green, and blue pucks in the central workspace ($|x|, |y| \le 0.2$ m) with instructions sampled from fixed templates. An evaluation trial on the spatial axis moves all pucks to the table rim ($|x|, |y| \in [0.2, 0.26]$ m) while keeping objects, colors, camera pose, and phrasing identical to training. An evaluation trial on the synonym axis keeps the layout nominal but substitutes "crimson puck" for "red puck".

When performance drops, the drop is attributed directly to the isolated axis rather than confounded scene changes.

## Mathematics

### Factored generalization gap

Let $\mathcal M$ denote a policy trained with random seed $s \in \mathcal S$. For a condition $c \in \mathcal C$, let $\hat S_c(s) \in [0, 1]$ be the empirical success rate over $N$ evaluation episodes. The in-distribution condition is denoted $c_0$.

The seed-matched generalization gap is:

$$\Delta_c(s) = \hat S_c(s) - \hat S_{c_0}(s)$$

Reporting the average gap $\bar{\Delta}_c = \frac{1}{|\mathcal S|}\sum_{s \in \mathcal S} \Delta_c(s)$ accounts for seed-to-seed variance in base capability. A policy whose base success varies from 0.92 to 0.99 across seeds might show an identical relative degradation of $-0.15$ on a spatial shift. Computing unaligned differences between separate seed sets introduces spurious variance.

### Statistical intervals

For $k$ successes out of $N$ independent trials, the standard normal approximation interval $\hat p \pm z\sqrt{\hat p(1-\hat p)/N}$ breaks down near 0 and 1, producing intervals that extend outside $[0, 1]$. We use the Wilson score interval with continuity correction:

$$w = \frac{2k + z^2 \pm z \sqrt{z^2 + 4k(1 - k/N)}}{2(N + z^2)}$$

At 95% confidence ($z = 1.96$) and $N = 100$, an outcome of 98 successes yields $[0.929, 0.995]$, accurately capturing the bounded probability mass.

```python file=examples/l22_5_vla_evaluation.py
import argparse
import json
import multiprocessing
import os
from concurrent.futures import ProcessPoolExecutor
from pathlib import Path

import numpy as np

from mjcourse import stats
from mjcourse.vla import evaluation as ev

FAST = os.environ.get("MJC_FAST") == "1"
RUNS = Path(__file__).resolve().parents[1] / "runs" / "vla"


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--vision", default="keypoint", choices=["patch", "keypoint", "oracle"])
    parser.add_argument("--seeds", type=int, nargs="+", default=[0] if FAST else [0, 1, 2])
    parser.add_argument("--episodes", type=int, default=2 if FAST else int(os.environ.get("MJC_EPISODES", "100")))
    args = parser.parse_args()
    models = {s: RUNS / f"minivla_{args.vision}_s{s}_pos.pt" for s in args.seeds}
    missing = [str(p) for p in models.values() if not p.exists()]
    if missing:
        raise SystemExit(f"train these first (examples/l22_4_train_minivla.py --state 2): {missing}")
    jobs = [(str(path), c, 3000 + seed, i) for seed, path in models.items() for c in ev.CONDITIONS for i in range(args.episodes)]
    workers = int(os.environ.get("SLURM_CPUS_PER_TASK", min(32, os.cpu_count() or 1)))
    with ProcessPoolExecutor(workers, mp_context=multiprocessing.get_context("spawn")) as pool:
        records = list(pool.map(ev.evaluate_one, jobs, chunksize=4))
    for job, rec in zip(jobs, records):
        rec["model_seed"] = int(Path(job[0]).stem.split("_s")[1].split("_")[0])
    (RUNS / f"eval_{args.vision}.json").write_text(json.dumps(records))
    print(f"MiniVLA ({args.vision}), {len(args.seeds)} seeds, {args.episodes} episodes per condition and seed")
    print(f"  {'condition':<16}{'axis':<15}{'success per seed [95% Wilson]':<62}{'mean':>6}{'gap to in distribution':>26}")
    base = {s: np.mean([r["success"] for r in records if r["condition"] == "in distribution" and r["model_seed"] == s])
            for s in args.seeds}
    for c in ev.CONDITIONS:
        cells, rates = [], []
        for s in args.seeds:
            ok = [r["success"] for r in records if r["condition"] == c and r["model_seed"] == s]
            lo, hi = stats.wilson_interval(int(sum(ok)), len(ok))
            cells.append(f"{np.mean(ok):.2f} [{lo:.2f}, {hi:.2f}]")
            rates.append(np.mean(ok))
        gaps = [rates[j] - base[s] for j, s in enumerate(args.seeds)]
        gap = "" if c == "in distribution" else f"{np.mean(gaps):+.2f} ({', '.join(f'{g:+.2f}' for g in gaps)})"
        print(f"  {c:<16}{ev.AXES[c]:<15}{'  '.join(cells):<62}{np.mean(rates):>6.2f}{gap:>26}")
    print(f"wrote {RUNS / f'eval_{args.vision}.json'}")


if __name__ == "__main__":
    main()
```

### Analyzing the failure axes

Language vocabulary collapses while structure holds. Paraphrasing templates ("push the red puck into zone left") drops only 13 percentage points. Unseen synonyms ("crimson token") collapse performance by 76 percentage points. The wordpiece tokenizer maps unseen names to out-of-vocabulary embeddings that the attention layers cannot ground. Large foundation VLAs mitigate this only when pretraining data covers the synonyms.

Spatial extrapolation degrades smoothly. When pucks lie near the rim, the pusher approaches from steeper angles, occasionally brushing against the outer boundary or nudging adjacent pucks. The gap is $-0.32$, demonstrating that imitation policies do not generalize uniformly over workspace geometry.

Color shifts confound token binding. When puck colors shift toward intermediate hues, visual tokens for the target puck attend weakly to the language prompt, leading the pusher to contact distractor pucks.

Actuator speed limits degrade closed-loop completion. Slowing the maximum speed from 0.20 m/s to 0.15 m/s causes a 28 point drop primarily due to episode timeouts ($t > 12$ s), demonstrating that fixed-horizon benchmarks conflate tracking precision with execution speed.

### Generalization on the 7-DOF Franka manipulator and the LIBERO benchmark

The same factored evaluation protocol extends to multi-task manipulation suites. The standard evaluation standard for Vision-Language-Action policies is the LIBERO benchmark (Liu et al., arXiv:2306.03310), which operates the 7-DOF Franka Emika Panda arm in MuJoCo across four distinct suites:

1. `libero_spatial` (10 tasks): Identical objects placed in novel spatial configurations (for example, "pick up the black bowl between the plate and the ramekin and place it on the plate").
2. `libero_object` (10 tasks): Manipulating novel object categories within familiar workspace layouts.
3. `libero_goal` (10 tasks): Different procedural goals executed in an identical kitchen environment.
4. `libero_10` / `libero_long` (10 tasks): Multi-step long-horizon manipulation requiring sequenced sub-goals (such as "turn on the stove and put the moka pot on it").

def profile_franka_rollout(env: FrankaVLA, steps: int = 20) -> dict[str, float]:
    env.reset()
    latencies_control: list[float] = []
    latencies_obs: list[float] = []

    for _ in range(steps):
        t0 = time.perf_counter()
        # Dual-camera rendering matching LIBERO (agentview and eye_in_hand)
        _ = env.render("top", width=64, height=64)
        _ = env.render("gripper/wrist", width=64, height=64)
        _ = env.state(include_velocity=False)
        t1 = time.perf_counter()

        action = franka_expert_action(env)
        env.step(action)
        t2 = time.perf_counter()

        latencies_obs.append((t1 - t0) * 1000.0)
        latencies_control.append((t2 - t1) * 1000.0)

    mean_obs_ms = float(np.mean(latencies_obs))
    mean_ctrl_ms = float(np.mean(latencies_control))
    loop_hz = 1000.0 / (mean_obs_ms + mean_ctrl_ms)

    return {
        "obs_latency_ms": mean_obs_ms,
        "control_step_ms": mean_ctrl_ms,
        "effective_loop_hz": loop_hz,
    }

Two architectural insights emerge from this comparison:
First, spatial generalization (`libero_spatial`) separates 2D image tokenizers from 3D-aware spatial representations. Autoregressive 2D patch encoders plateau between 84% and 88%, whereas models with explicit depth or 3D token lifting reach 97%.
Second, long-horizon tasks (`libero_10`) expose compounding drift. Without temporal action chunking, OpenVLA drops from 88.4% on single-step objects to 53.7% on long tasks. Predictive flow matching and structured state-space models maintain higher fidelity (80% to 87%) over extended horizons.

## Debugging

**The aggregate metric trap.** If an experiment reports a single score averaged across all conditions ($0.71$), it conceals the fact that object size generalization is near perfect ($0.91$) while synonym understanding is near zero ($0.19$). Always publish the factored decomposition.

**Seed variance masking.** In the synonym condition, seed 0 achieves 0.02 while seed 1 achieves 0.32. A single seed trial would report either utter failure or modest viability. Three seeds with confidence intervals are required to reveal that language tokenization is fragile.

**Unmatched gap comparisons.** Never compute $\bar S_c - \bar S_{c_0}$ using separate seed groups. Calculate gaps per seed first, then average the differences.
