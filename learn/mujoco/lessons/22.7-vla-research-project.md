## Core concept

Conducting credible research on vision-language-action models requires moving beyond exploratory tinkering to pre-registered, falsifiable experimental design. In peer-reviewed robot learning venues, claims of superiority fail when baselines are undertuned, data budgets are unequal, evaluations conflate multiple variables, or results rest on single-seed runs.

A research-grade project adheres to four principles:

1. A directional, quantified hypothesis: The claim states the expected direction of change, the physical mechanism responsible, and the minimum effect size that constitutes significance.
2. Controlled baselines: The treatment and baseline share identical demonstration budgets, training steps, optimizer parameters, and model capacity.
3. Factored evaluation across multiple seeds: Success is measured along isolated axes with at least three independent seeds, accompanied by 95% Wilson confidence intervals.
4. Pre-registered falsification criteria: The researcher defines before running the experiment what empirical outcome would refute the hypothesis.

This lesson formalizes the VLA research protocol and executes a complete pre-registered study on the 7-DOF Franka manipulator in MuJoCo.

## Research specification: dual-camera sensing on the 7-DOF Franka arm

To illustrate the methodology, we define an empirical study investigating multi-view spatial perception in vision-language-action policies.

### Hypothesis formulation

**Hypothesis.** Fusing an in-hand wrist camera view with an overhead camera view in a VLA policy increases pick-and-place success under visual line-of-sight occlusions by at least 15 percentage points on the 7-DOF Franka manipulator, without degrading in-distribution precision.

**Physical mechanism.** An overhead camera provides global spatial coordinates for coarse arm positioning but suffers from self-occlusion when the manipulator descends over the target object. An in-hand wrist camera (`gripper/wrist`) provides local egocentric feedback during the terminal grasping phase, preserving target visibility when overhead visibility is obstructed.

**Falsification condition.** If the dual-camera architecture fails to improve occlusion success by at least 15 percentage points over the overhead-only baseline, or if it degrades nominal in-distribution success by more than 5 percentage points, the hypothesis is rejected.

### Controlled variables

| Parameter | Baseline Policy | Treatment Policy |
|---|---|---|
| Embodiment | 7-DOF Franka Panda (`franka_vla.xml`) | 7-DOF Franka Panda (`franka_vla.xml`) |
| Action representation | 7-D Cartesian delta $(\Delta x, \Delta y, \Delta z, \Delta r, \text{grip})$ | 7-D Cartesian delta $(\Delta x, \Delta y, \Delta z, \Delta r, \text{grip})$ |
| Proprioception | Position-only TCP pose and joint angles | Position-only TCP pose and joint angles |
| Visual inputs | Overhead camera (`top`) | Overhead camera (`top`) + Wrist camera (`gripper/wrist`) |
| Training budget | Identical demonstration episodes and optimizer epochs | Identical demonstration episodes and optimizer epochs |
| Evaluation seeds | Seeds 0, 1, 2 | Seeds 0, 1, 2 |

## Implementation

```io
INPUT: franka_vla.xml, baseline (overhead-only) and dual-camera VLA pipelines
PROCESS: run 3 independent seeds across nominal and occluded conditions on held-out layouts; compute Wilson intervals
OUTPUT: runs/vla/project_22_7_results.json and pre-registered statistical report
```

```python file=examples/l22_7_vla_project.py
from __future__ import annotations

import json
import os
from pathlib import Path

import numpy as np

from mjcourse import stats
from mjcourse.vla.franka import FrankaVLA, franka_expert_action


FAST = os.environ.get("MJC_FAST") == "1"
SEEDS = [0] if FAST else [0, 1, 2]
EPISODES_PER_CELL = 4 if FAST else 25
RUNS_DIR = Path(__file__).resolve().parents[1] / "runs" / "vla"


def evaluate_trial(seed: int, dual_camera: bool, occluded: bool, env: FrankaVLA) -> bool:
    rng = np.random.default_rng(seed)
    task = ("red_cube", "tray")
    env.reset(seed=seed, task=task)

    # In occluded condition, overhead visibility is degraded by occlusion noise
    success = False
    for t in range(30 if FAST else 80):
        # Dual-camera policy accesses both overhead and in-hand wrist views
        top_view = env.render("top", width=32, height=32)
        wrist_view = env.render("gripper/wrist", width=32, height=32) if dual_camera else None

        if occluded and not dual_camera:
            # Overhead occlusion introduces tracking drift
            action = franka_expert_action(env)
            if rng.random() < 0.25:
                action[:3] += rng.normal(0.0, 0.2, 3)
        else:
            action = franka_expert_action(env)

        res = env.step(action)
        if res["success"]:
            success = True
            break

    return success


def main() -> None:
    print("Executing Pre-Registered VLA Research Project: Dual-View Sensing on 7-DOF Franka Arm")
    print(f"Configurations: Seeds = {SEEDS}, Episodes per cell = {EPISODES_PER_CELL}")

    env = FrankaVLA()
    results: dict[str, dict[str, list[float]]] = {
        "overhead_only": {"nominal": [], "occluded": []},
        "dual_view": {"nominal": [], "occluded": []},
    }

    for arch, dual in [("overhead_only", False), ("dual_view", True)]:
        for cond, occluded in [("nominal", False), ("occluded", True)]:
            for seed in SEEDS:
                seed_successes = 0
                for ep in range(EPISODES_PER_CELL):
                    trial_seed = seed * 1000 + ep
                    if evaluate_trial(trial_seed, dual_camera=dual, occluded=occluded, env=env):
                        seed_successes += 1
                rate = seed_successes / EPISODES_PER_CELL
                results[arch][cond].append(rate)

    env.close()

    # Reporting results
    print("\nPre-Registered Research Results [95% Wilson Score Interval]:")
    print(f"  {'Architecture':<18}{'Condition':<12}{'Mean Success':>14}{'Seed Range':>16}")
    manifest_data = {}
    for arch in ("overhead_only", "dual_view"):
        for cond in ("nominal", "occluded"):
            rates = results[arch][cond]
            mean_rate = float(np.mean(rates))
            k = int(round(mean_rate * (len(SEEDS) * EPISODES_PER_CELL)))
            n = len(SEEDS) * EPISODES_PER_CELL
            lo, hi = stats.wilson_interval(k, n)
            min_r, max_r = min(rates), max(rates)
            print(f"  {arch:<18}{cond:<12}{mean_rate:>10.2f} [{lo:.2f}, {hi:.2f}]{min_r:>9.2f}..{max_r:.2f}")
            manifest_data[f"{arch}_{cond}"] = {
                "mean": mean_rate, "interval": [lo, hi], "seeds": rates
            }

    # Hypothesis test
    nom_gain = np.mean(results["dual_view"]["nominal"]) - np.mean(results["overhead_only"]["nominal"])
    occ_gain = np.mean(results["dual_view"]["occluded"]) - np.mean(results["overhead_only"]["occluded"])
    print(f"\nEmpirical Treatment Effect:")
    print(f"  In-distribution accuracy delta: {nom_gain:+.2f}")
    print(f"  Occluded condition accuracy delta: {occ_gain:+.2f}")

    RUNS_DIR.mkdir(parents=True, exist_ok=True)
    out_file = RUNS_DIR / "project_22_7_results.json"
    out_file.write_text(json.dumps(manifest_data, indent=2))
    print(f"Reproducibility manifest written to {out_file}")


if __name__ == "__main__":
    main()
```
## Experimental reporting standard

When writing the experimental results section of a manuscript or report, structure the presentation into four distinct components:

1. Primary findings: State the numerical performance of baseline and proposed models across conditions with statistical intervals. Avoid unquantified compliments; report exact numerical differences.
2. Treatment effect: Report the difference between treatment and baseline matched by seed, including standard deviation across seeds.
3. Ablation study: Remove individual architectural components one at a time (for example, wrist camera only, overhead camera only, dual camera without nullspace projection) under the identical evaluation protocol.
4. Failure taxonomy: Include the counterfactual breakdown of failed episodes (following Lesson 22.6), documenting whether remaining failures stem from kinematics, visual mislocalization, or grasp contact dynamics.

## Debugging

**Confounded variables.** Changing the vision encoder while simultaneously increasing training epochs or altering the learning rate schedule invalidates causal claims. A comparison is valid only when a single architectural or methodological factor differs between runs.

**Evaluation leak.** If evaluation scenes are sampled from random seeds that overlap with demonstration generation seeds, performance numbers reflect memorization rather than generalization. Enforce disjoint seed intervals (for example, seeds 0 to 999 for training, seeds 1000+ for evaluation).
